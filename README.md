# prototipo-monitoreo-de-par-metros-el-ctricos-en-ATS
En este respositorio se almacena toda la información obtenida, diseñada e implementada para el proyecto de monitoreo de parámetros eléctricos en sistemas de transferencia automatica y generadores diésel. Aqui se encuentran desde los codigos base, diseños, manuales y fichas tecnicas necesarias para desarrollar el proyecto.
